## Pricing by System Type

### School Management System
- Segment: Sekolah agama swasta, PAS-linked, komuniti
- Setup: RM 1,500 – 3,000
- Monthly: RM 250 – 350/bln
- Notes: Budget dari komuniti/AJK — jangan over-quote. Setup boleh waive untuk close deal. Jangan turunkan monthly.
- Add-on Payment Gateway: + RM 80/bln + ToyyibPay fee (RM1+1% per transaksi, sekolah tanggung)
- Reference: SRITI School System (2026-04-30)

### CRM System
- Segment: SME, small local business, solo entrepreneur
- Basic (Contacts + Pipeline + Notes): RM 3,500 + RM 200/bln
- Standard (+ Reminders + Activity Log + Reports): RM 5,500 + RM 300/bln
- Pro (+ WA Integration + Multi-user): RM 8,000 + RM 400/bln
- Timeline: Basic ~2 minggu, Standard ~3-4 minggu, Pro ~6 minggu
- Small local business (e.g. playgroup, kedai): RM 2,500 setup + RM 180-200/bln
- Reference: Messy Playgroup Desaru (2026-04-30)

### Salon Management System
- Reference: HMS Salon — full POS + appointments + customers + staff + reports
- Production live system, Vercel + Supabase

### General Rules
- Monthly fee jangan turun — recurring income penting
- Setup fee boleh sacrifice untuk close deal
- Infra cost (Supabase + Hetzner + domain) ~RM 145/bln per project
- Margin target minimum RM 150-200/bln selepas infra
- Sekolah/NGO/PAS-linked: budget terhad, keputusan melalui AJK — GB jadi champion internal
- Untuk first client dalam segment baru: prioritize portfolio + testimoni > setup fee

## Negotiation Strategy

1. **Jangan sebut harga terus dalam WA** — demo dulu, harga lepas value nampak
2. **Kalau terpaksa jawab WA** — sebut monthly je, defer setup fee ke demo
3. **Frame harga vs alternatif** — banding dengan kos kerani/part-time, bukan dengan RM0
4. **Annual payment diskaun** — jimat ~2 bulan: contoh RM 350 × 12 = RM 4,200 → offer RM 3,500
5. **Upsell timing** — pitch add-on lepas 2-3 bulan client dah guna dan trust sistem
