# 🧱 PROJECT BRIEF — WEBSITE SYARIKAT KONTRAKTOR BINAAN

## 📌 1. Latar Belakang Projek
Syarikat kontraktor binaan ini memerlukan sebuah laman web korporat moden untuk memperkenalkan profil syarikat, perkhidmatan, dan portfolio projek yang telah dijalankan.  
Website ini akan menjadi medium utama untuk meningkatkan kredibiliti syarikat di mata pelanggan, agensi kerajaan, dan rakan industri — terutamanya sebagai rujukan dalam permohonan tender serta pemasaran digital.

---

## 🎯 2. Objektif Projek
1. Menyediakan laman web profesional yang mencerminkan imej syarikat kontraktor yang berpengalaman dan berintegriti.  
2. Memaparkan portfolio projek (gambar & video) dengan susun atur moden dan mesra peranti mudah alih.  
3. Memudahkan pelanggan menghubungi syarikat melalui borang emel atau pautan media sosial.  
4. Mengurangkan kos penyelenggaraan dengan menggunakan platform hosting percuma dan stabil (Cloudflare Pages).  
5. Menyediakan struktur yang mudah dikembangkan (boleh tambah projek baru tanpa deploy semula).

---

## 🧩 3. Skop & Komponen Utama

| Komponen | Penerangan |
|-----------|------------|
| **1. Reka Bentuk UI/UX** | Antaramuka moden menggunakan Tailwind CSS, warna korporat (biru/kelabu/putih), dan tipografi profesional. |
| **2. Halaman Utama (Home)** | Hero banner dengan tagline syarikat, ringkasan servis & pautan ke gallery projek. |
| **3. Tentang Kami (About)** | Profil syarikat, pengalaman, pensijilan (CIDB/ISO), dan nilai korporat. |
| **4. Perkhidmatan (Services)** | Senarai kepakaran: kerja bangunan, jalan & infrastruktur, M&E, renovasi. |
| **5. Projek (Gallery)** | Senarai projek dengan gambar + YouTube embed video. Auto-load dari `projects.json`. |
| **6. Hubungi Kami (Contact)** | Borang Formspree + alamat, nombor telefon, e-mel, dan peta lokasi. |
| **7. Hosting & Domain** | Cloudflare Pages (free hosting, SSL, CDN global) + domain syarikat. |
| **8. CMS Ringan (JSON/Google Sheet)** | Boleh tambah projek baru tanpa perlu deploy semula laman. |
